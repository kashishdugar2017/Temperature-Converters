# Temperature-Converters
Two programs: one converts Fahrenheit to Celsius, and the other does the reverse.

## How it works
- For the Fahrenheit to Celsius converter we use the formula: `(F-32)*5/9`
- For the Celsius to Fahrenheit converter we use the formula: `(C*9/5)+32`

## How to run
1. Choose which one you want to use
2. Make a new Cargo project
3. In main.rs, paste the program you chose
4. Run it with `cargo run`
